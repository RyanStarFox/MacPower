# 购买 Apple 开发者证书之后

还没购买，下面的事先不做。当前发布继续用临时签名，不公证，也不做桌面小组件。

个人开发者账号每年 99 美元。买的是开发者计划，不是上架 App Store。MacPower 继续在 GitHub、Gitee、阿里云盘、百度网盘发行。

## 公证安装包

现在 `scripts/make_dmg.sh` 用 `codesign --sign -` 做临时签名。别的 Mac 上，用 Apple Development 证书签过的包会显示为已损坏，所以公开发布包保持临时签名。系统会拦住第一次打开，说明写在 `README.md`、`README.en.md`、`如何安装.md`、`how2install.md`。

买到证书之后：

- 申请 **Developer ID Application** 证书，用来签发给别人的 Mac。本机调试继续用 Apple Development。
- `make_dmg.sh` 改为用 Developer ID 签名，再对 dmg 和 zip 做公证。应用和里面的扩展必须是同一个 Team ID。
- 安装说明里删掉「没有公证、第一次打开会被拦住」这段，改成公证之后的打开方式。
- 发布流程仍不要在上传时替换或重启 `/Applications/MacPower.app`。

## 桌面小组件

可以做，不必上架 App Store。Mac 桌面小组件是放在应用里的 WidgetKit 扩展，macOS 14 起可以放到桌面上。

临时签名做不了。系统会单独启动扩展，只接受 Developer ID 签名；发给别人的包还要公证。临时签名的扩展不会出现在小组件列表里。

买到证书并完成上面的签名和公证之后：

- 在现有工程里加一个 Widget 扩展，跟菜单栏应用打在同一个包里。
- 菜单栏应用和小组件不是同一个进程。电量、刻度这些状态用 App Group 共享。App Group 也要这个开发者账号。
- 用同一个 Team 的 Developer ID 签名并公证后，别的 Mac 才能添加这个小组件。
